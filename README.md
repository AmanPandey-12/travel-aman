# Travel-Aman 🌍✈️\n\n**Travel-Aman** is a modern, full-stack travel planning and booking platform showcasing the beauty and culture of India, with a special focus on the historical city of Bhopal. Built with cutting-edge technology, Travel-Aman makes discovering, planning, and booking unforgettable travel experiences effortless.\n\n## 🎯 Project Overview\n\nTravel-Aman is designed to celebrate Indian heritage, promote cultural tourism, and provide seamless travel booking experiences. Whether you're exploring ancient monuments, savoring traditional cuisine, or attending vibrant festivals, Travel-Aman connects you with authentic Indian experiences.\n\n**Creator:** Aman Pandey  \n**Portfolio Project:** Travel-Aman  \n**Version:** 2.0 (Upgraded)\n\n## ✨ Key Features\n\n### 🔐 **Secure Authentication**\n- Google OAuth Login - Sign in with your Google account\n- Email/Password Authentication - Traditional secure login\n- JWT Token-based session management\n- Encrypted password storage with bcryptjs\n\n### 💳 **Payment Integration**\n- Razorpay payment gateway integration\n- Secure payment processing for bookings\n- Hotel reservations and activity tickets\n- Order management and transaction history\n- Payment success/failure handling\n\n### 🇮🇳 **Cultural Exploration**\n- **Indian Heritage Sites** - Explore ancient monuments and historical landmarks\n- **Traditional Cuisine** - Discover authentic Indian recipes and food culture\n- **Festivals & Celebrations** - Learn about India's vibrant festivals\n- **Bhopal Showcase** - Special focus on Bhopal's palaces, markets, and heritage\n- **Local Customs & Traditions** - Cultural guides for respectful tourism\n- **Regional Stories** - In-depth narratives about different Indian regions\n\n### 📱 **Responsive Design**\n- Mobile-first approach\n- Fully responsive UI across all devices\n- Optimized performance for tablet and desktop\n- Smooth animations and transitions\n- Dark mode support\n- Enhanced accessibility features\n\n### 🗺️ **Travel Planning Tools**\n- Interactive maps and location discovery\n- Itinerary builder\n- Travel guides and recommendations\n- Real-time information updates\n- Personalized travel suggestions\n\n### 🌐 **Multi-Backend Support**\n- Node.js/Express backend\n- Firebase Firestore database\n- Scalable API architecture\n- RESTful API endpoints\n\n## 🛠️ Tech Stack\n\n### Frontend\n- **Framework:** Next.js 13+\n- **Language:** TypeScript\n- **Styling:** Tailwind CSS\n- **UI Components:** Custom + Tailwind\n- **State Management:** React Hooks\n\n### Backend\n- **Runtime:** Node.js\n- **Framework:** Express.js\n- **Database:** Firebase Firestore\n- **Authentication:** Google OAuth 2.0, JWT\n- **Payment Gateway:** Razorpay\n\n### Tools & Libraries\n- **Authentication:** Firebase Admin SDK, jsonwebtoken\n- **Security:** bcryptjs, cors\n- **Environment:** dotenv\n- **API:** RESTful architecture\n\n## 📦 Installation & Setup\n\n### Prerequisites\n- Node.js 16+ and npm/yarn\n- Firebase account\n- Razorpay account (for payment processing)\n- Google OAuth credentials\n\n### Frontend Setup\n\n```bash\n# Clone the repository\ngit clone https://github.com/AmanPandey-12/travel-aman.git\ncd travel-aman\n\n# Install dependencies\nnpm install\n# or\nyarn install\n\n# Create .env.local file\ncp .env.example .env.local\n\n# Add your environment variables\n# NEXT_PUBLIC_FIREBASE_API_KEY=your_key\n# NEXT_PUBLIC_GOOGLE_CLIENT_ID=your_client_id\n# RAZORPAY_KEY_ID=your_key\n\n# Run development server\nnpm run dev\n# or\nyarn dev\n\n# Open http://localhost:3000 in your browser\n```\n\n### Backend Setup\n\n```bash\n# Navigate to backend directory\ncd backend\n\n# Install dependencies\nnpm install\n\n# Create .env file\ncp .env.example .env\n\n# Add backend environment variables\n# FIREBASE_PROJECT_ID=your_project_id\n# FIREBASE_PRIVATE_KEY=your_private_key\n# RAZORPAY_KEY_SECRET=your_secret_key\n# JWT_SECRET=your_jwt_secret\n\n# Start the backend server\nnpm start\n# Server runs on http://localhost:5000\n```\n\n## 🚀 Firebase Configuration\nNEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_api_key\nNEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_firebase_auth_domain\nNEXT_PUBLIC_FIREBASE_PROJECT_ID=your_firebase_project_id\nNEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_firebase_storage_bucket\nNEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_firebase_sender_id\nNEXT_PUBLIC_FIREBASE_APP_ID=your_firebase_app_id\n\n# Google OAuth\nNEXT_PUBLIC_GOOGLE_CLIENT_ID=your_google_client_id\nGOOGLE_CLIENT_SECRET=your_google_client_secret\n\n# Razorpay Payment Gateway\nNEXT_PUBLIC_RAZORPAY_KEY_ID=your_razorpay_key_id\nRAZORPAY_KEY_SECRET=your_razorpay_key_secret\n\n# Backend API\nNEXT_PUBLIC_API_URL=http://localhost:5000/api\n\n# JWT Secret\nJWT_SECRET=your_super_secret_jwt_key\n```\n\nFor backend, create `backend/.env`:\n\n```env\nPORT=5000\nNODE_ENV=development\n\n# Firebase Admin\nFIREBASE_PROJECT_ID=your_project_id\nFIREBASE_PRIVATE_KEY=your_private_key\nFIREBASE_CLIENT_EMAIL=your_client_email\n\n# Razorpay\nRAZORPAY_KEY_ID=your_key_id\nRAZORPAY_KEY_SECRET=your_key_secret\n\n# JWT\nJWT_SECRET=your_jwt_secret\nJWT_EXPIRE=7d\n\n# CORS\nCORS_ORIGIN=http://localhost:3000\n```\n\n## 📖 Usage
